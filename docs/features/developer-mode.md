# Developer & Benchmark Mode

Sentry includes a comprehensive **Developer Mode** designed for AI researchers, security auditors, and developers building autonomous web agents.

---

## Features

- **Live Execution Tracing:** View every LLM call, token latency, prompt payload, and raw model response.
- **AgentDojo & Adversarial Test Suites:** Run built-in security benchmark suites directly against live or mocked web pages.
- **Token & Cost Profiler:** Breakdown of input tokens, output tokens, cache hits, and estimated monetary cost.
- **Trace Export:** Export complete session traces to `.json`, `.md` (Markdown report), or `.csv`.

---

## Accessing Developer Mode

Navigate to `sentry://developer` or toggle Developer Mode in **Settings → Advanced**.
