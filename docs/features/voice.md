# Voice Control & Narration

Sentry provides full hands-free voice control and audio feedback for accessibility and rapid task initiation.

---

## Voice Input (Speech-to-Text)

- **Microphone Hotkey:** Hold `Space` while in the command box or click the microphone icon.
- **Audio Processing:** Uses Web Audio API and on-device Whisper (or browser native speech recognition) to transcribe spoken instructions in real-time.
- **Natural Language Parsing:** Speak naturally: *"Find cheap round-trip flights from New York to London departing next Friday."*

---

## Audio Feedback (Text-to-Speech)

- Sentry can narrate task progress, warnings, and result summaries.
- Configurable voice speed, pitch, and verbosity in **Settings → Voice**.
- Ideal for vision-impaired users or multitasking workflows.
