# Keyboard Shortcuts

Sentry supports comprehensive keyboard shortcuts for both browser navigation and agent control.

---

## Agent Controls

| Windows / Linux | macOS | Action |
|-----------------|-------|--------|
| `Ctrl + Shift + Space` | `Cmd + Shift + Space` | **Toggle Agent Command Box** |
| `Ctrl + Shift + P` | `Cmd + Shift + P` | **Pause / Resume Current Task** |
| `Ctrl + Shift + S` | `Cmd + Shift + S` | **Stop / Abort Current Task** |
| `Hold Space` (in command box) | `Hold Space` | **Push-to-Talk (Voice Input)** |
| `Escape` | `Escape` | Close Command Box / Dismiss Notification |

---

## Tab & Window Navigation

| Windows / Linux | macOS | Action |
|-----------------|-------|--------|
| `Ctrl + T` | `Cmd + T` | New Tab |
| `Ctrl + W` | `Cmd + W` | Close Active Tab |
| `Ctrl + Tab` | `Ctrl + Tab` | Next Tab |
| `Ctrl + Shift + Tab` | `Ctrl + Shift + Tab` | Previous Tab |
| `Ctrl + 1` to `9` | `Cmd + 1` to `9` | Switch to Tab N |
| `Ctrl + Shift + T` | `Cmd + Shift + T` | Reopen Closed Tab |
| `Ctrl + L` / `Alt + D` | `Cmd + L` | Focus Address Bar |

---

## Page Navigation

| Windows / Linux | macOS | Action |
|-----------------|-------|--------|
| `Ctrl + R` / `F5` | `Cmd + R` | Reload Page |
| `Ctrl + Shift + R` | `Cmd + Shift + R` | Hard Reload (Bypass Cache) |
| `Alt + Left Arrow` | `Cmd + [` | Go Back |
| `Alt + Right Arrow` | `Cmd + ]` | Go Forward |
| `Ctrl + Plus` | `Cmd + Plus` | Zoom In |
| `Ctrl + Minus` | `Cmd + Minus` | Zoom Out |
| `Ctrl + 0` | `Cmd + 0` | Reset Zoom to 100% |

---

## Quick Navigation to Internal Pages

- `sentry://newtab` — New tab start page
- `sentry://settings` — User settings & model configuration
- `sentry://history` — Browsing history
- `sentry://bookmarks` — Bookmark manager
- `sentry://downloads` — Downloads manager
- `sentry://recipes` — Saved task recipes
- `sentry://developer` — Developer & benchmark mode
