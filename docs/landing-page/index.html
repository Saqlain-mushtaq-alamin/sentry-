How Sentry Is Different

Three core pillars of trust, transparency, and local control.

🛡️

1. Trust: Action Firewall

Every planned action is classified into 4 risk tiers. Read operations proceed instantly, while state-modifying or financial actions require your explicit confirmation.

📜

2. Transparency: Audit Log

Every single step, DOM selector, timestamp, and model thought is logged to a tamper-evident audit log with instant inspection and undo capabilities.

🔒

3. Control: Local-First AI

Run completely offline using Ollama (Llama 3.1, Qwen 2.5) with zero telemetry and zero cloud dependencies. Your data stays on your machine.

Frequently Asked Questions

Is Sentry really 100% private with Ollama?

Yes. When running with Ollama, all inference happens directly on your CPU/GPU. No page snapshots, queries, or logs leave your computer.

Can Sentry run Chrome extensions?

Yes. Sentry supports Chrome extensions including ad blockers (uBlock Origin), password managers (1Password, Bitwarden), and developer tools.

How does Sentry handle banking or sensitive websites?

You can set banking domains to "Blocked" in Website Trust Mode, ensuring the agent is completely barred from interacting with them.
